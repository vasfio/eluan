## Decisions I was unsure about

- **Which component.** I used `Toggle` with `pressed` set to `mode === "dark"`, which gives an `aria-pressed` toggle button. I also considered `Button variant="ghost" size="icon"` with a label that changes, `Switch` (better for a labelled row on a settings page), and the `SegmentedControl` light/dark picker the docs landing page uses. "Toggle" plus the header-icon pattern decided it.
- **Dim mode.** Eluan has three modes. Turning dark off goes back to the last non-dark mode (kept in a ref), not always to `light`. That costs a few extra lines. Also, after a reload while in dark mode the ref falls back to `light`.
- **Label.** I kept a fixed `aria-label="Dark mode"` and let `aria-pressed` carry the state, following the WAI-ARIA toggle-button pattern. The docs' own demo instead uses "Toggle bold", and their shell switcher names the mode you would switch to.
- **Icon.** A fixed `Moon` icon, with the pressed styling showing the state. I did not swap Sun/Moon, because that would mix two ways of showing state.
- **`Mode` type.** I derived it as `ReturnType<typeof useEluanTheme>["mode"]` instead of importing a named type. The docs mention a `modes` re-export, but I never confirmed the name of a `Mode` type.
- **`followSystemMode`.** The docs don't say whether `setMode` stops the provider from following the OS, or whether `mode` reports the resolved value while it follows. I assumed `mode` is the effective mode.
- **Persistence and SSR flash.** I left both to the root `EluanProvider` config (`persist`, the inline head script) and did not touch them, because the provider is already set up and isn't in this file.
- **`"use client"`.** Added because the component uses hooks and this might be a Next.js App Router app. Outside RSC it's a harmless string.
- **Size and variant.** Toggle's default size and variant. The docs offer `iconSm` for a compact icon-only toggle, but their own icon-only demo uses the default size.
- **No tooltip or `title`.** Sighted mouse users get no visible text label. I didn't add `Tooltip` or `title` to keep the change small. The docs' own shell switcher does use `title`.
- **Placement.** I only wrote the component. Mounting it (header, settings) is up to the teammate.
- **Nothing passed to `className` or `style`.** The docs say component styling is closed.
