# @vasf/ragnar-web

> Marketing and web-specific React components — hero sections, pricing tables, footers, and more. Part of the [Ragnar](https://github.com/frolda/ragnar) design system.

Builds on top of `@vasf/ragnar-core` and shares the same token system.

## Install

```bash
pnpm add @vasf/ragnar-web @vasf/ragnar-core @vasf/ragnar-tokens
```

## Use

```tsx
import "@vasf/ragnar-core/styles.css"
import "@vasf/ragnar-tokens/css"
import "@vasf/ragnar-web/styles.css"

import { Hero, Pricing } from "@vasf/ragnar-web"
```
