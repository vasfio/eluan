# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** through GitHub Security Advisories:

**<https://github.com/vasfio/eluan/security/advisories/new>**

Do not open a public issue, discussion, or pull request for a security problem — that discloses the issue before a fix is available.

When reporting, please include:

- the affected package(s) and version(s),
- a description of the vulnerability and its impact, and
- steps to reproduce (a minimal example is ideal).

We aim to acknowledge reports within a few days and will keep you informed as we work on a fix. Once a fix ships, we're glad to credit you in the advisory — let us know if you'd prefer to remain anonymous.

## Supported versions

Eluan is pre-1.0. Security fixes are applied to the latest published release of each package (`@eluan/tokens`, `@eluan/core`, `@eluan/theme-generator`). Earlier versions are not maintained.
